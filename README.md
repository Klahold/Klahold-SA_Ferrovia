# Klahold-SA_Ferrovia
Um projeto de um aplicativo móvel para gerenciamento de uma ferrovia.

# Descrição
Um aplicativo para a "HERMES ENTERPRISE", uma empresa com um logotipo que inclui uma locomotiva e o ano "1987". O aplicativo possui funcionalidades de login para trabalhadores e recuperação de senha.
O aplicativo oferece diferentes menus para funcionários e chefes, incluindo opções como "Rotas", "Avisos", "Manutenção", "Dashboard" e "Relatório". O "Dashboard" fornece informações como velocidade, horário de partida/chegada, distância percorrida, consumo de combustível e alertas
Há também funcionalidades para gerenciamento de funcionários, incluindo busca e cadastro, além de relatórios de desempenho e avisos importantes.

# Funcionalidades
- O sistema exibe os status dos trems, horários e alertas em tempo real.
- O sistema permite o planejamento e ajuste de trajetos de acordo com imprevistos ou mudanças na demanda.
- O sistema permite o monitoramento de inspeções e alertas para manutenção preventiva.
- O sistema exibe os dados sobre desempenho, consumo de energia e eficiência operacional.
- O sistema mostra os avisos sobre atrasos, falhas mecânicas e atualizações de segurança.


# Como Executar
Para começar você deve criar uma conta com seu email (ou código) e uma senha.
Após criar uma conta faça login e você estará na tela de menu.
Caso você se esquecer da senha em algum momento você poder clicar na opção "Esqueci minha senha" para substituir a atual por uma nova.
Na tela inicial haverá 5 opções, cada uma será explicada aqui.
A opção de Rotas permite ver as rotas atuais dos trens disponíveis, use isso para saber onde esperar pelo seu trem.
Notificações podem ser ativadas para avisar você que o trem está chegando perto do destino desejado, assim você estará pronto para embarcar
quando chegar, além disso ele mostra a velocidade atual, a distancia, a quantidade de combustível e o horário de partida/chegada do trem.
Você também consegue ver o conteúdo dos vagões do trem escolhido, assim você pode ter uma decissão melhor ao escolher um.
Linhas fechadas para manutenções ou outros motivos serão adicionadas aos alertas do Dashboard para manter-lhe informado.
A opção de Dashboard é onde você seleciona o trem que deseja, é sugerido selecionar um trem no dashboard antes de usar a opção de Rotas.
Manutenção permite você ver se os trens possuem problemas, caso um for detectado, haverá um aviso perto do trem, evite andar nele e reporte
o problema e então espere até ele ser solucionado ou use outro trem.
A opção de Relatórios permite-lhe ver as opiniões dos outros sobre o trem, além disso você pode escrever seu próprio relatório para descrever
como foi a jornada e se teve algum problema.
A seção de Avisos é usada para alertar você sobre algum incoveniência, sendo trems com problemas, linhas atrasando trens e atualizações de segurandças
ou do aplicativo.
Caso você for um funcionário, uma nova opção estará disponível para você, ela permite você ver e cadastrar funcionários para a equipe, clicando no pessoa desejada
permite você visualizar os dados dela como Nome Completo, Data de Nascimento, Naturalidade e Nacionalidade.
